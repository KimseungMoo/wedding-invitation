# 2026-08-25 feat 개발자 버전 청첩장 `/us`

## 무엇을

하객장 흐름은 두고 `/us`를 붙였다. 1차는 크림 하객장과 같은 얼굴이라 개성이 약했고, 이후 참고 데모 개발자 페이지처럼 다크 에디터 얼굴로 다시 짰다.

## 왜

“부드러운 청첩장 하나 더”가 아니라 도구처럼 보이게. 신부는 개발자가 아니라 일기 본문에 git 용어는 넣지 않았다.

## 어떻게

- `src/wedding.config.ts`에 이름·날짜·장소·인사말·계좌·스토리 카피를 모음
- `/invitation`은 config를 읽고, 푸터에 `/us` 작은 링크
- `/us`: 에디터 바 · 타이핑 · `&&` 이름 · 장소 배너 · 카운트다운·달력 · 봇/메모/리마인드/일기 패널 · 다크 장소·계좌
- 모노는 JetBrains Mono. 하객장 크림 Location/Account는 `/us`에 이어 붙이지 않음

## 확인

- 변경 파일 eslint 통과
- `yarn build` — `/us` 정적 라우트 생성
- 일기 본문에 금지 단어(branch, repository, merge, commit, PR, CI, deploy, git log) 없음
- 브라우저에서 `/us`가 하객장과 다른 얼굴인지, 왕복 링크가 되는지 확인
