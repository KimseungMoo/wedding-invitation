# 종이 청첩장 자료조사

2026-10-26 (Asia/Seoul)

앞면은 이미 손그림. 안쪽이 비어 보여서, 한국 종이청첩장 관례부터 다시 정리했다.

## 결론 (이 카드에 쓸 것)

1. **안쪽 왼쪽** — 인사 + 혼주(빈칸) + 이름 + 일시·장소  
2. **안쪽 오른쪽** — **약도 필수** + 지하철·셔틀·주차  
3. **뒷면** — **QR 메인 배치** (권장)  
4. 장식 일러스트는 안쪽에 안 씀. 약도는 길 안내라서 예외.

허전함의 원인: 안쪽에 인사만 있고 약도·교통·혼주 블록이 비었기 때문.

## 2단 접이 표준 구성

출처: 크몽 청첩장 가이드, tip.0k-cal, ChungDoi, 바른손/아이패밀리 혼주 표기

| 면 | 흔히 넣는 것 |
| --- | --- |
| 1면 앞 | 이름·날짜·대표 이미지/문구 |
| 2면 안쪽 좌 | 인사말, 혼주·신랑신부 |
| 3면 안쪽 우 | 일시·장소 **또는** 약도·교통 |
| 4면 뒤 | 약도 보충 / 디자인 / **QR** |

크몽 예시 하나는 좌=약도, 우=인사+일시.  
1단(엽서)형은 앞=이름·날짜, 뒤=인사+약도.

우리 앞면이 이미 장식형이니, 안쪽은 **정보 밀도**를 올리는 쪽이 맞다.

## 필수 정보

빠진 채로 보내면 당일 전화 온다. (디어미오, 링크메리, 씬쿵)

- 예식장 **정식 명칭 + 층 + 홀**
- 도로명 주소 (택시·내비용)
- 요일 포함 일시
- **약도** (종이에서는 이미지 약도가 기본)
- 지하철 **출구 번호** · 셔틀 탑승지
- 주차: 무료 시간 / 등록 방법
- 혼주 표기 (양가 확인 후)

계좌는 종이에 넣지 않는 집이 늘었다. 모바일로 넘기는 선택 OK.

## 약도

- 종이: 약도 이미지 + 주소 텍스트
- 모바일: 네이버/카카오 길찾기 버튼이 더 실용적 → QR로 연결
- 넣을 랜드마크: 가까운 역 출구, 큰 도로명, 찾기 쉬운 건물 2~3개
- 예식장 제공 약도 있으면 그걸 기준으로, 셔틀·주차는 예식 직전 재확인

우리 웹에 이미 있는 약도 요소를 종이용으로 단순화:

- 도로: 선릉로 · 도산대로 · 학동사거리
- 핀: 더채플앳청담
- 하단: 강남구청역 3번 출구 · 셔틀
- 주변: 도산공원, CGV, 삼성스토어, 영동고 (필요 시 일부만)

## QR — 뒷면이 본진

출처: Birevet, Utterly Printable, 레디매리

| 위치 | 평가 |
| --- | --- |
| **뒷면 하단** | 가장 흔함. 앞·안쪽 디자인 안 건드림 |
| 안쪽 하단 | 가능. 약도와 경쟁하면 답답해짐 |
| 봉투 속 작은 카드 | 본카드 디자인을 안 건드리고 싶을 때 |
| 하트·원 재단 | 코너 손실 → 스캔 실패. 비추천 |

인쇄 규칙:

- 최소 **2×2cm**, 여백(quiet zone) 유지
- 밝은 바탕 + 어두운 코드
- 옆에 **무엇을 여는지** 문장 필수
- 시안을 iPhone·Android로 스캔 후 대량 인쇄

뒷면 문구 예:

> QR코드를 스캔하시면  
> 오시는 길과 모바일 청첩장을 확인하실 수 있습니다.

어르신용으로 짧은 URL을 QR 옆에 같이 적는 것도 좋음.

## 우리 케이스 판단

| 질문 | 답 |
| --- | --- |
| 안쪽이 왜 허한가 | 약도·교통·혼주 자리가 비었음 |
| 약도 위치 | 안쪽 오른쪽 전체 |
| QR 위치 | **뒷면** 권장. 안쪽에는 “자세한 안내는 뒷면 QR” 한 줄만 |
| 안쪽 QR 중복? | 굳이 안 넣어도 됨. 넣으면 작게만 |
| 계좌 | 종이 X, 모바일 O |
| 혼주 | 이름 받기 전엔 빈칸 |

## 시안 방향 (반영)

```
앞면(기존)     |  안쪽 좌              |  안쪽 우           |  뒷면
손그림         |  인사                 |  약도             |  QR
SAVE THE DATE  |  혼주 빈칸 · 이름     |  지하철·셔틀·주차 |  안내 문구
               |  일시 · 장소          |                   |  짧은 URL
```
