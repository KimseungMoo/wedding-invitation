2단 접이. 펼치면 왼쪽은 인사, 오른쪽은 때·곳·우표 QR.

혼주 성함은 아직 비워 두었다. 알려주면 넣는다.

## QR을 자연스럽게 넣는 법

인쇄 QR은 정사각형, 흰 여백, 한 변 2.5cm 이상.
하트·원으로 자르면 코너가 날아가서 스캔이 잘 안 된다.

### 1. 우표 — 지금 시안

점선 네모 안에 QR, 아래 작게 `모바일 청첩장`.
앞면 낙서랑 제일 잘 붙는다. 스캔도 안전하다.
인쇄소에 `qr-print.png`를 따로 줘도 된다.

### 2. 문 창문

웹 인트로가 문 열기다.
작은 문을 그리고, 창문에 QR을 넣는다.
문은 테두리만. QR은 네모 그대로.

세계관은 이어지는데, 문 그림이 커지면 예식 정보가 밀린다.

### 3. 봉투와 왁스실

웹에 실랍 인트로도 있다.
실을 QR로 쓰면 동그라미로 잘리니 쓰지 말 것.
봉투 그림 옆에 네모 우표로 붙이는 편이 낫다.

### 4. 약도 아래

기능은 분명하다. “길 보고 들어오세요.”
다만 낙서 앞면과는 안내문 느낌이 난다.
지금 시안은 십자 약도는 장식으로만 두고, QR은 아래로 뺐다.

### 5. 하트 프레임 — 비추천

예쁘다. 코너가 잘리면 스캔이 죽는다.

## 파일

| 파일 | 용도 |
| --- | --- |
| `inner-left-ko.png` / `inner-right-ko.png` | 한글 안쪽, 인쇄용 |
| `inner-left-en.png` / `inner-right-en.png` | 영어 안쪽 |
| `inner-spread-ko.png` | 펼친 미리보기 |
| `qr.svg` / `qr.png` / `qr-print.png` | 스캔 확인된 QR |
| `compose_inner.py` | 문구 고치고 다시 그리기 |

인쇄 카드는 130×174mm 또는 A5.
크림 종이. QR은 축소해도 한 변 2.5cm는 남길 것.

다시 그리기:

```
python3 paper-invitation/compose_inner.py
```
