# 종이청첩장 안쪽

글과 QR만. 일러스트 없음.
2단 접이. 왼쪽 인사, 오른쪽 때·곳·우표 QR.

## 문구 출처

| 부분 | 어디서 |
| --- | --- |
| 날짜·시간 | 웹 초대장 / `invitation/page.tsx` 푸터 |
| 장소·주소·셔틀 | 웹 `Location` 섹션 |
| 신랑·신부 이름 | 웹 `김승무` `성은지` |
| 왼쪽 인사 | 새로 씀. 앞면·웹에 있던 문장 아님 |
| 계좌 | 종이에 안 넣음. QR → 모바일 |

웹에 쓰던 『모순』 인용은 안쪽에 안 넣었다. 쓰고 싶으면 아래 대체안.

혼주 성함은 아직 없음. 알려주면 넣는다.

## QR

점선 네모(우표) 안에 정사각 QR. 아래 `모바일 청첩장`.
한 변 2.5cm 이상. 하트·원으로 자르지 말 것.
