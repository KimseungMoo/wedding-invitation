# 종이청첩장 안쪽 · 뒷면

자료조사 요약은 `자료조사.md`.

장식 일러스트 없음. 구조 블록(패널·달력·약도·표)로 채움.
QR은 **뒷면**이 메인.

## 레이아웃 규칙

- 좌우 공통 여백 · 같은 콘텐츠 폭
- 중간 블록(달력 / 약도) 시작선 `Y_BLOCK` 고정 → 펼치면 정렬
- 왼쪽: 인사 → 혼주 2열 패널 → 2월 달력(21일 강조) → 일시·장소
- 오른쪽: 장소 요약 → 약도 패널 → 교통 표 패널
- 달력은 일요일 시작 (2027-02-21 = 일요일)

## 면 구성

| 면 | 내용 |
| --- | --- |
| 앞면 | 기존 손그림 (그대로) |
| 안쪽 왼쪽 | 인사 · 혼주 2열 · 달력 · 일시·장소 |
| 안쪽 오른쪽 | 약도 · 교통 표 |
| 뒷면 | QR · 안내 문구 · URL |

## 문구 출처

| 부분 | 어디서 |
| --- | --- |
| 날짜·시간·장소·셔틀·버스·주차 | 웹 초대장 / `Location` · 푸터 |
| 약도 요소 | 웹 `Location.tsx` 약도 단순화 |
| 이름 | 김승무 · 성은지 |

| 혼주 | 빈칸. 이름 오면 채움 |
| 계좌 | 종이 X → 뒷면 QR |
